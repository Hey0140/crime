6. 약품 라벨 프린터 사용 설명서

문서명: MED-LABEL Mini 220 사용 설명서

비치 위치: VIP 약품실 라벨 프린터 옆

문서 상태: 사용 흔적 있음 / 일부 페이지 접힘

1. 장비 개요

MED-LABEL Mini 220은 약품 용기, 보관 트레이, 임시 처방 봉투에 부착하는 라벨을 출력하는 소형 라벨 프린터이다.

사용 목적:

  • 약품명 표기
  • 환자명 표기
  • 복용 시간 표기
  • 보관 위치 표기
  • 유효기한 표기
  • 임시 처방 코드 출력

2. 기본 출력 방식

라벨 출력은 두 가지 방식으로 가능하다.

A. 등록 사용자 출력

의료진 개인 계정으로 로그인하여 출력한다.

이 경우 출력 로그에 사용자 이름이 남는다.

B. 게스트 출력

약품실 내부 네트워크에 연결된 상태에서 임시 라벨을 출력한다.

이 경우 출력 로그에는 사용자 이름이 남지 않고, “GUEST PRINT”로 기록된다.

게스트 출력은 응급 상황에서 빠르게 라벨을 출력하기 위해 허용된 기능이다.

3. 게스트 출력 제한사항

게스트 출력 시 다음 정보는 자동 기록된다.

  • 출력 시각
  • 라벨 양식 번호
  • 프린터 번호
  • 출력 매수
  • 연결된 단말기 번호

단, 사용자의 개인 이름은 기록되지 않는다.

주의:

게스트 출력 기록만으로 실제 출력자를 특정할 수 없다.

약품실 출입 기록, CCTV, 지문, 라벨 부착 흔적 등과 함께 확인해야 한다.

4. 최근 출력 로그 예시

출력 시각 출력 방식 라벨 양식 출력 매수 사용자
18:21 등록 사용자 일반 처방 라벨 2 백기태
18:42 게스트 출력 VIP 개인약품 라벨 1 GUEST PRINT
18:57 등록 사용자 응급 트레이 라벨 1 간호팀 공용

  • 환자명
  • 약품 코드
  • 복용 시간
  • 보관 위치
  • 담당자 확인란
