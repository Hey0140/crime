점검일시: 2026년 12월 25일 20:39

점검 대상

유리관 내부 우측 하단에 설치된 비상 해제 버튼.

정상 작동 시 내부 인물이 버튼을 2초 이상 누르면 다음 순서로 작동한다.

  1. 외부 잠금 해제
  2. 유리관 전면 패널 15cm 개방
  3. 관리실 경고음 발생
  4. 조명 자동 점등

발견 상태

비상 버튼은 눌린 상태에서 원위치로 돌아오지 않았다.

버튼과 버튼 테두리 사이에 아주 작은 금속 조각이 끼어 있었으며, 이로 인해 버튼이 정상적으로 눌리거나 복귀하지 못한 것으로 보인다.

버튼 주변에는 손톱으로 긁은 듯한 자국이 있고, 내부 패널 하단에는 미세한 혈흔이 확인되었다.

단순 고장 가능성 낮음.

18:45 테스트 당시 정상 작동 확인됨.
